### Pergunta 1 — Fundamentos de HTML5

**Pergunta:** Qual é a função do HTML5 no desenvolvimento web e como se organiza a estrutura básica de um documento HTML?

**Resposta obtida:** O **HTML (HyperText Markup Language)** é a linguagem de marcação responsável por definir a estrutura e a semântica de todo o conteúdo da web. Ao contrário de uma linguagem de programação tradicional, ele não processa algoritmos ou regras de negócio; sua função é rotular e organizar os elementos por meio de **tags** (etiquetas) para que o navegador consiga interpretá-los e exibi-los adequadamente.

Abaixo está a dissecação completa da anatomia de um documento HTML5, do topo à base.

---

### 1. A Instrução `<!DOCTYPE html>`

A primeira linha de qualquer documento não é uma tag HTML, mas uma instrução preliminar de configuração.

* **O que ela faz:** Informa ao navegador qual versão do HTML deve ser utilizada para interpretar e renderizar o documento — no caso, a declaração simples `<!DOCTYPE html>` ativa a versão mais recente da linguagem (HTML5).
* **Por que é perigoso omitir:** Sem essa instrução, o navegador entra em um modo de compatibilidade (*quirks mode*), renderizando elementos com estilos padrão legados, o que pode causar falhas em espaçamentos e incompatibilidades em tags modernas.
* **Sintaxe:** A especificação aceita tanto caracteres maiúsculos quanto minúsculos (`<!doctype html>` ou `<!DOCTYPE html>`).

---

### 2. A Tag Raiz: `<html lang="pt-BR">`

É a tag que envolve todo o código da página.

* **Papel estrutural:** Comporta-se como o elemento "pai" raiz de todas as outras tags.
* **Atributo `lang`:** Especifica o idioma principal do documento (como `pt-BR` para português do Brasil). Esse atributo orienta ferramentas de indexação e leitores de tela utilizados para acessibilidade.

---

### 3. A Seção Invisível: `<head>` (Metadados)

A seção `<head>` armazena informações e configurações destinadas ao navegador, a mecanismos de busca e a serviços externos, não fazendo parte do conteúdo visível da página.

Os elementos fundamentais dentro do `<head>` são:

1. **`<meta charset="UTF-8">`:** Define a página de código e o conjunto de caracteres do documento. Sem essa instrução, idiomas como o português apresentam falhas na renderização de caracteres acentuados e cedilhas.
2. **`<meta name="viewport" content="width=device-width, initial-scale=1.0">`:** Configuração essencial para **páginas responsivas**. Ela instrui o navegador a ajustar as proporções do documento de acordo com a largura da tela do dispositivo (smartphones, tablets ou computadores).
3. **`<title>`:** Tag obrigatória pela especificação. Define o texto exibido na aba ou na barra de título do navegador.
4. **`<link>`:** Estabelece vínculos com arquivos externos, como folhas de estilo CSS (`<link rel="stylesheet" href="...">`) e o ícone da aba (`<link rel="icon" ...>`).

---

### 4. A Seção Visível: `<body>` e a Árvore DOM

A tag `<body>` engloba todo o conteúdo visível exibido na janela do navegador.

* **A Árvore DOM (Document Object Model):** Ao processar o HTML, o navegador cria na memória uma estrutura hierárquica de nós com relações de parentesco ("pai", "filho" e "irmãos"). Por exemplo, `<html>` é pai de `<head>` e `<body>`; `<head>` e `<body>` são irmãs entre si.
* **Tags genéricas vs. Tags semânticas:**
  * **Tags genéricas (`<div>` e `<span>`):** Têm propósito genérico e servem essencialmente para agrupar blocos ou trechos de texto para fins de estilização CSS, sem carregar significado próprio.
  * **Tags semânticas estruturais:** Definem o significado e o propósito de cada bloco. Elas são cruciais para que buscadores priorizem o site e para que leitores de tela garantam a acessibilidade de pessoas com deficiência visual.

Principais tags estruturais do HTML5 para o `<body>`:
* **`<header>`:** Cabeçalho do documento ou de uma seção.
* **`<nav>`:** Bloco específico para agrupar links de navegação do site.
* **`<main>`:** Representa a área de conteúdo central e predominante da página.
* **`<section>`:** Seção temática de conteúdo.
* **`<article>`:** Item independente e autônomo dentro de um grupo ou página.
* **`<footer>`:** Rodapé do documento.
* **`<h1>` até `<h6>`:** Títulos hierárquicos de importância (`<h1>` deve ser único por página para o título principal, enquanto `<h2>` a `<h6>` identificam seções e subtítulos).

---

### Código Prático: Modelo Estrutural Completo

Aqui está o esqueleto canônico que reúne todos esses fundamentos:

```html
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <!-- Metadados essenciais -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Estrutura Base HTML5</title>

    <!-- Folha de estilos externa -->
    <link rel="stylesheet" href="estilos.css">
  </head>
  <body>
    <!-- Cabeçalho institucional e navegação -->
    <header>
      <nav>
        <ul>
          <li><a href="#inicio">Início</a></li>
          <li><a href="#sobre">Sobre</a></li>
        </ul>
      </nav>
    </header>

    <!-- Conteúdo principal da página -->
    <main>
      <h1>Título Principal da Página</h1>
      
      <section id="sobre">
        <h2>Seção Sobre</h2>
        <p>Parágrafos estruturados com conteúdo de texto descritivo.</p>
      </section>
    </main>

    <!-- Rodapé -->
    <footer>
      <p>&copy; 2026 - Todos os direitos reservados.</p>
    </footer>
  </body>
</html>
```

---

### Diferenciação Pedagógica (Fundamentos das Fontes vs. Recomendações Práticas)

* **O que está rigorosamente comprovado nas fontes:** A exigência do `<!DOCTYPE html>` para evitar o modo de compatibilidade, a obrigatoriedade da tag `<title>`, o papel das metatags para caracteres e responsividade, e o uso de tags semânticas para acessibilidade e SEO.
* **Recomendações complementares de mentoria:** 
  1. *Indentação consistente:* Alinhe sempre os elementos "irmãos" na mesma margem e adicione recuos (*tabs* ou espaços) para elementos "filhos", garantindo legibilidade e manutenção limpa do código.
  2. *Atalho de produtividade:* No VS Code, você não precisa digitar essa estrutura do zero toda vez: digitar `!` seguido da tecla `Tab` ou `Enter` insere automaticamente esse esqueleto padrão.

### Pergunta 2 — CSS3 e estilização

**Pergunta:** Como o CSS é utilizado para estilizar páginas web e qual é a diferença entre seletores, propriedades e valores?

**Resposta obtida:** O **CSS (*Cascading Style Sheets* ou Folhas de Estilo em Cascata)** é a linguagem criada especificamente para separar a camada estrutural do documento (definida pelo HTML) de sua camada estética e de apresentação. Enquanto o HTML organiza os dados e o esqueleto da página em tags, o CSS é responsável por definir cores, tipografia, dimensões, espaçamentos e layouts.

Abaixo está a explicação didática de como o CSS se conecta ao HTML e a anatomia exata de suas regras de estilo.

---

### 1. Como o CSS é Utilizado para Estilizar Páginas Web

O CSS pode ser incluído em uma aplicação web de **três maneiras distintas**:

1. **Inline (Atributo `style`):** As regras são escritas diretamente no elemento HTML por meio do atributo `style` (por exemplo: `<p style="color: blue;">`). As fontes destacam que essa abordagem **não é recomendada na prática**, pois anula a principal vantagem do CSS, que é manter o código visual separado do conteúdo estrutural.
2. **Interno (Tag `<style>`):** As regras são agrupadas dentro do cabeçalho `<head>` da página, delimitadas pela tag `<style>`. É útil para testes rápidos ou regras restritas a uma única página, mas ainda mantém o estilo no mesmo arquivo do HTML.
3. **Externo (Arquivo `.css` vinculado via `<link>`):** É o método padrão e recomendado na arquitetura web. Os estilos são escritos em um arquivo próprio com extensão `.css` (por exemplo, `estilos.css`) e vinculados no `<head>` do HTML através da tag `<link>`:
   ```html
   <link rel="stylesheet" href="estilos.css">
   ```
   Essa abordagem permite reaproveitar o mesmo arquivo de design em várias páginas e manter o projeto organizado e sustentável.

---

### 2. A Anatomia de uma Regra CSS: Seletor, Propriedade e Valor

Toda regra CSS segue uma estrutura formal bem definida:

```css
seletor {
  propriedade: valor;
}
```

A distinção entre as três partes é a seguinte:

#### A. Seletor: *O Alvo (Quem recebe o estilo)*
O **seletor** é a instrução que busca e aponta para quais elementos do documento HTML as diretrizes visuais devem ser aplicadas. Ele pode selecionar elementos de diferentes formas:
* **Por nome da tag:** estiliza todas as tags daquele tipo na página (ex.: `p`, `h1`, `body`).
* **Por classe (prefixo `.`):** estiliza qualquer elemento que contenha aquele atributo `class` (ex.: `.destaque`, `.botao`).
* **Por identificador único (prefixo `#`):** aponta para um elemento que possua um atributo `id` específico (ex.: `#topo`, `#valor`).
* **Universal (`*`):** seleciona todos os elementos do documento de uma só vez, comumente usado para *resets* de margens e preenchimentos.

#### B. Propriedade: *O Aspecto (O que será alterado)*
A **propriedade** define a característica visual ou dimensional exata do elemento que você deseja modificar. Ela sempre vem antes dos dois pontos (`:`).
* *Exemplos comuns:* `color` (cor do texto), `background-color` (cor de fundo), `font-size` (tamanho da fonte), `width` (largura) e `margin` (espaçamento externo).

#### C. Valor: *A Configuração (Como deve ficar)*
O **valor** é a especificação concreta atribuída àquela propriedade. Ele fica entre os dois pontos (`:`) e o ponto e vírgula (`;`).
* *Exemplos:* para a propriedade `color`, o valor pode ser um nome (`blue`), um código hexadecimal (`#3D3D3D`), ou uma função RGB (`rgb(255, 0, 0)`); para `font-size`, pode ser uma medida como `18px`, `1.5rem` ou `2em`.

---

### Exemplo Prático Comentado

Veja abaixo como essas peças trabalham juntas em um arquivo externo:

```css
/* 1. SELETOR DE TAG: aplica a todos os parágrafos */
p {
  color: #2e4255;          /* Propriedade: color | Valor: tom azul escuro */
  font-size: 1rem;         /* Propriedade: font-size | Valor: 1rem */
  line-height: 1.5;        /* Propriedade: line-height | Valor: 1.5 */
}

/* 2. SELETOR DE CLASSE: aplica a elementos com class="botao" */
.botao {
  background-color: blue;  /* Propriedade: background-color | Valor: blue */
  color: white;            /* Propriedade: color | Valor: white */
  text-decoration: none;   /* Propriedade: text-decoration | Valor: none */
}

/* 3. SELETOR DE ID: aplica apenas ao elemento com id="cabecalho-principal" */
#cabecalho-principal {
  text-align: center;      /* Propriedade: text-align | Valor: center */
  border-bottom: 1px solid black; /* Propriedade abreviada de borda */
}
```

---

### Diferenciação Pedagógica (Fundamentos das Fontes vs. Recomendações de Mentoria)

* **Documentado rigorosamente nas fontes:**
  * A sintaxe obrigatória: `seletor { propriedade: valor; }`, onde cada declaração deve ser finalizada por ponto e vírgula (`;`).
  * O peso de **especificidade** dos seletores: seletores de tag valem 1 ponto, seletores de classe valem 10 pontos e seletores de ID valem 100 pontos, determinando qual regra vence em caso de conflito de estilos.
  * A recomendação de evitar o atributo inline `style` por quebrar a separação de responsabilidades.

* **Recomendações complementares de mentoria:**
  * **Evite estilizar usando IDs no CSS:** Embora o seletor `#id` funcione perfeitamente, seu alto peso de especificidade (100 pontos) torna muito difícil sobrescrever estilos no futuro. Dê preferência a classes (`.classe`), reservando IDs para âncoras de links ou seleções em JavaScript.
  * **Sintaxe limpa:** Mantenha sempre um espaço após os dois pontos (`color: red;`) e indente as propriedades com recuo dentro das chaves para garantir legibilidade e manutenção rápida do código.
